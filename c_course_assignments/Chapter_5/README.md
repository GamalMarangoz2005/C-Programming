# Assignment 1 Description

## Write a C program that implement 2 functions:

1. Function to get the maximum of 4 values.
2. Function to get the minimum of 4 values.

The program will ask the user first to enter the 4 values, then print the maximum number and minimum number of them.

# Assignment 2 Description

## Write a simple calculator that does the following..
1. Ask the user to enter the Operation ID.
2. Depending on the operation, the program will ask the user either to enter 1 operand or 2 operands.
3. The program will execute the operation and print the result.

> Each operation should be implemented in a standalone function.
