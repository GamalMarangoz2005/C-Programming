# Assignment 1 & 2 Description

## Write C code that manage a small school
The school has 3 classes and each class contains 10 students.
- Define three arrays for the three classes with a length of 10.
- Save a random numbers in all array elements to indicate the students grade.
- The program will calculate and display the following statistics 

### Statistics 
1. Minimum value.
2. Maximum value.
3. Number of passed students.
4. Number of failed students.
5. Highest Grade.
6. Lowest Grade.
7. Average grade knowing that the total grade is from 100 and the minimum passing grade is 50.
